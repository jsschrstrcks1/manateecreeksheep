# HETEROSIS (Hybrid Vigor) in Sheep Breeding: Comprehensive Research Summary

## 1. How Heterosis Works in Sheep Crosses

Heterosis is the superiority of crossbred offspring over the average of their purebred parents. It is calculated as:

```
% Heterosis = [(crossbred_mean - purebred_parent_mean) / purebred_parent_mean] * 100
```

Heterosis arises from increased heterozygosity in crossbred animals. Non-additive gene effects (dominance and epistasis) are the primary drivers. A critical principle: **heterosis is inversely related to heritability**. Lowly heritable traits (reproduction, survival, fitness) show the most heterosis, while highly heritable traits (carcass, wool quality) show the least.

## 2. Individual Heterosis vs. Maternal Heterosis

**Individual (direct) heterosis** is the advantage expressed by the crossbred animal itself (e.g., a crossbred lamb grows faster than the purebred average).

**Maternal heterosis** is the advantage conferred by having a crossbred dam (e.g., a crossbred ewe produces more milk, has better fertility, weans heavier lambs regardless of the lamb's own genetics).

Research consistently shows **maternal heterosis is more economically important than individual heterosis**. In cattle data (applicable in principle to sheep), crossbred dams raising crossbred offspring weaned 23.3% more weight per female exposed, of which approximately two-thirds (14.8%) was from maternal heterosis and one-third (8.5%) from individual heterosis.

### Does Adding a 3rd or 4th Breed Add MORE Heterosis?

**Yes, but through different mechanisms:**

**2-way cross (A x B):**
- 100% individual heterosis in the F1 lamb
- 0% maternal heterosis (dam is purebred)

**3-way terminal cross (C sire x [A x B] dam):**
- 100% individual heterosis (lamb is a cross)
- 100% maternal heterosis (dam is F1 crossbred)
- This is the gold standard: maximum heterosis from both sources

**Rotational systems at equilibrium:**

| System | Individual Heterosis | Maternal Heterosis |
|---|---|---|
| 2-breed terminal | 100% | 0% |
| 3-breed terminal | 100% | 100% |
| 2-breed rotation | ~67% | ~67% |
| 3-breed rotation | ~86-87% | ~86-87% |
| Rota-terminal | ~90% overall | Variable |

The 3-breed terminal cross achieves the maximum possible heterosis but requires purchasing all replacement females. The combined effects of maternal heterosis, individual heterosis, and complementarity can increase total productivity by **40-50%** relative to the purebred average.

## 3. Retained Heterosis in Composite/Synthetic Breeds

### The Core Formula

Retained heterosis in a composite breed is calculated as:

```
Retained_Heterosis = 1 - SUM(Pi^2)
```

Where `Pi` is the fractional contribution of each breed to the composite.

When all breeds contribute equally (each at 1/n), this simplifies to:

```
Retained_Heterosis = 1 - (1/n) = (n-1)/n
```

### Examples by Number of Breeds

| Number of Breeds | Equal Fractions | Retained Heterosis |
|---|---|---|
| 2 | 1/2, 1/2 | 1 - (0.25 + 0.25) = **50%** |
| 3 | 1/3, 1/3, 1/3 | 1 - (0.111 + 0.111 + 0.111) = **67%** |
| 4 | 1/4, 1/4, 1/4, 1/4 | 1 - (4 * 0.0625) = **75%** |
| 5 | 1/5 each | **80%** |
| 8 | 1/8 each | **87.5%** |

### Unequal Breed Fractions Reduce Retained Heterosis

| Breed Fractions | Calculation | Retained Heterosis |
|---|---|---|
| 1/2 + 1/2 | 1 - (0.25 + 0.25) | 50% |
| 5/8 + 3/8 | 1 - (0.3906 + 0.1406) | 47% |
| 3/4 + 1/4 | 1 - (0.5625 + 0.0625) | 38% |

**Equal breed fractions maximize retained heterosis** for any given number of breeds.

### What Happens in F2 (F1 x F1 Same Cross)?

When F1 animals from a 2-breed cross are mated inter se (F1 x F1), the F2 generation retains only **50%** of the original F1 heterosis. This is a **one-time loss** between F1 and F2. If inbreeding is avoided, subsequent generations (F3, F4, etc.) maintain that same 50% level.

The Boujenane et al. (1999) study on D'man x Sardi sheep confirmed this experimentally. Their results showed that the proportion of retained heterosis was not less than the proportion of retained heterozygosity for most traits, supporting that dominance (not epistasis) is the primary basis for heterosis in sheep.

### Heterosis Expectations by Generation in a 2-Breed Synthetic

| Generation | Individual Heterosis (Hi) | Maternal Heterosis (Hm) | Paternal Heterosis (Hp) |
|---|---|---|---|
| F1 | 1.0 Hi | 0 Hm | 0 Hp |
| F2 | 0.5 Hi | 1.0 Hm | 1.0 Hp |
| F3+ | 0.5 Hi | 0.5 Hm | 0.5 Hp |

Note: The F2 actually has MORE maternal heterosis than the F1 (because F2 lambs have F1 dams), even though individual heterosis drops by half.

### F1 x Different Breed (Backcross or 3-Way Cross)

Crossing an F1 (A x B) female to a completely different breed C sire gives 100% individual heterosis (assuming breed C is unrelated to A and B) AND 100% maternal heterosis. This is vastly superior to F1 x F1 inter se mating.

### Real-World Composite Breed Examples

| Breed | Composition | Predicted Retained Heterosis |
|---|---|---|
| **Polypay** | 1/4 Dorset, 1/4 Rambouillet, 1/4 Targhee, 1/4 Finnsheep | 75% |
| **C-IV** | 1/2 Romanov, 1/4 Katahdin, 1/4 White Dorper | 62.5% |

Polypay: `1 - (4 * 0.25^2) = 1 - 0.25 = 0.75` (75%)
C-IV: `1 - (0.50^2 + 0.25^2 + 0.25^2) = 1 - (0.25 + 0.0625 + 0.0625) = 0.625` (62.5%)

### Parasite Resistance (FEC)

Parasite resistance is primarily a **breed effect** rather than a heterosis effect, but crossbreeding can transfer resistance:

- Katahdin ewe lambs had FEC **45% lower** than Dorset crosses and **62% lower** than Dorper crosses
- St. Croix and Barbados Blackbelly show the highest resistance among studied breeds
- A study on Rhoen x Merino Land sheep found heterosis for FEC favored the crossbred group for Haemonchus contortus resistance
- Hair sheep breeds generally have more resistant individuals than wool breeds
- FEC heritability is moderate (0.20-0.35), so both selection and crossbreeding are useful tools

## 5. Which Traits Show the MOST vs. LEAST Heterosis?

### MOST heterosis (low heritability, fitness-related):
1. **Ewe productivity** (lbs lamb weaned/ewe exposed): 17-18%
2. **Lambs reared/ewe exposed**: 14-15%
3. **Lambs born/ewe exposed**: 5-15%
4. **Lamb survival to weaning**: 9-10% (up to 19% in some crosses)
5. **Ewe fertility**: 8.7% maternal

### LEAST heterosis (high heritability, non-fitness):
1. **Carcass traits** (loin eye area, fat thickness, yield grade): ~0%
2. **Wool quality** (fiber diameter, staple length): ~0%
3. **Milk production** (in non-dairy breeds): near 0%
4. **Birth weight**: 2-3%
5. **Conception rate**: 2.6%

### Why Composite Traits Show Such High Heterosis

"Ewe productivity" (weight of lamb weaned per ewe exposed) is a **multiplicative composite** of several component traits:

```
Ewe_Productivity = Fertility x Prolificacy x Lamb_Survival x Lamb_Growth_Rate
```

Even small heterosis in each component multiplies:
```
(1.087 fertility) x (1.032 prolificacy) x (1.098 survival) x (1.05 weaning_wt)
= 1.294 = 29.4% total advantage
```

This explains why composite traits show 15-44% heterosis while individual component traits show only 3-10%.

## 6. Negative Heterosis

### Wool Medullation
**Undesirable positive heterosis was found for medullation percentage** for all crossbred combinations. Higher medullation is undesirable in wool (medullated fibers are coarser, less valuable). This means crossbreeding actually made wool quality **worse** than either parent.

### Fiber Diameter
Crossing fine-wool breeds with meat breeds predictably produces **coarser wool** -- the crossbred is intermediate, but the wool is less valuable than the fine-wool parent. This is not heterosis per se but rather an unfavorable shift toward the mid-parent mean for a trait where one parent is superior.

### Carcass Composition
When a lean breed is crossed with a fat breed, the crossbred is intermediate. If your market demands lean carcasses, the crossbred may be **worse** than the lean purebred parent.

### Number of Lambs Weaned
Nitter (1978) reported that direct heterosis estimates ranged from **-4% to +15%** for number of lambs weaned, meaning some specific breed crosses actually showed negative heterosis for this trait.

### Environmental Maladaptation
Highly productive global breeds crossed with adapted local breeds sometimes produced offspring that were **unable to forage, survive, and reproduce at acceptable levels** when denied high levels of feeding, housing, and veterinary care. The crossbred was effectively worse than both parents in a low-input environment.

## 7. Complementarity vs. Heterosis

These are the **two distinct benefits** of crossbreeding:

**Heterosis**: Non-additive genetic effects that cause crossbreds to exceed the average of their parents. Automatic result of crossing genetically different populations. Greatest for fitness/reproductive traits.

**Complementarity**: Combining the additive breed strengths of different breeds to produce offspring with a better combination of traits than any single breed offers. This works for **highly heritable traits** where heterosis is negligible.

### Example: Meat Breed x Hair Breed
- A **Texel** (heavy muscling, fast growth, excellent carcass) crossed on a **Katahdin** (parasite resistance, heat tolerance, easy lambing, low maintenance) dam:
  - The lamb gets **complementarity**: intermediate muscling + intermediate parasite resistance (better than either parent alone in total utility)
  - The lamb gets **individual heterosis**: ~5% better growth, ~10% better survival
  - The Katahdin dam provides her adapted maternal traits (this is a breed effect, not heterosis)

### Key Distinction for Code

```
Total_crossbred_advantage = Breed_additive_effects + Individual_heterosis + Maternal_heterosis + Complementarity
```

- **Breed effects** are additive and predictable from the parent breed averages
- **Heterosis** is non-additive and provides a bonus above the mid-parent value
- **Complementarity** is the strategic combination of different breed strengths (requires terminal crossbreeding to fully exploit)

## Formulas for Code Implementation

### 1. Retained Heterosis in Composites

```python
def retained_heterosis(breed_fractions):
    """
    Calculate retained heterosis from breed fractions.
    breed_fractions: list of floats that sum to 1.0
    Returns: fraction of F1 heterosis retained (0-1)
    """
    sum_squared = sum(p**2 for p in breed_fractions)
    return 1.0 - sum_squared
```

### 2. F1 Heterosis Calculation

```python
def f1_heterosis_pct(crossbred_mean, parent_a_mean, parent_b_mean):
    """Calculate percent heterosis for F1 cross."""
    midparent = (parent_a_mean + parent_b_mean) / 2.0
    return ((crossbred_mean - midparent) / midparent) * 100.0
```

### 3. Expected Performance of a Cross

```python
def expected_crossbred_performance(parent_a_mean, parent_b_mean,
                                     heterosis_pct):
    """Predict crossbred performance from parent means and heterosis."""
    midparent = (parent_a_mean + parent_b_mean) / 2.0
    return midparent * (1.0 + heterosis_pct / 100.0)
```

### 6. Composite Ewe Productivity Model

```python
def ewe_productivity(fertility, prolificacy, lamb_survival,
                     avg_weaning_wt):
    """
    Calculate lbs lamb weaned per ewe exposed.
    fertility: fraction of ewes that lamb (0-1)
    prolificacy: lambs born per ewe lambing
    lamb_survival: fraction surviving to weaning (0-1)
    avg_weaning_wt: average weaning weight per lamb (lbs)
    """
    return fertility * prolificacy * lamb_survival * avg_weaning_wt


def apply_heterosis_to_productivity(base_fertility, base_prolificacy,
                                      base_survival, base_wean_wt,
                                      heterosis_fraction=1.0):
    """
    Apply heterosis to each component of ewe productivity.
    heterosis_fraction: 1.0 for F1, 0.5 for F2 inter se, etc.
    """
    adj_fertility   = base_fertility   * (1 + 0.087 * heterosis_fraction)
    adj_prolificacy = base_prolificacy * (1 + 0.032 * heterosis_fraction)
    adj_survival    = base_survival    * (1 + 0.098 * heterosis_fraction)
    adj_wean_wt     = base_wean_wt     * (1 + 0.050 * heterosis_fraction)

    return ewe_productivity(adj_fertility, adj_prolificacy,
                            adj_survival, adj_wean_wt)
```
